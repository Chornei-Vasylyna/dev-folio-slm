# DevFolio

Платформа, де розробники створюють онлайн-портфоліо та резюме з експортом у PDF.

## Вимоги

Усі артефакти аналізу вимог знаходяться в папці [`/requirements`](./requirements):

| Файл | Зміст |
|------|-------|
| [SRS_v1.md](./requirements/SRS_v1.md) | Специфікація вимог (версія 1) |
| [requirements.md](./requirements/requirements.md) | 10 вимог: 5 функціональних і 5 нефункціональних |
| [user-stories.md](./requirements/user-stories.md) | 5 user stories з acceptance criteria |
| [backlog.md](./requirements/backlog.md) | Product backlog |
| [use-case-diagram.svg](./requirements/use-case-diagram.svg) | Діаграма сценаріїв використання |

Короткий підсумок:

- **Функціональні:** автентифікація, редагування портфоліо, каталог із пошуком, публічне резюме, PDF-експорт.
- **Нефункціональні:** безпека доступу, валідація даних, зручність, адаптивність, продуктивність.
- **Ролі:** Відвідувач, Автор профілю.
