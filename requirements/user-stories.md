# User stories

Формат: Як [роль], я хочу [функція], щоб [цінність].

## US-01. Створення портфоліо
**Як** розробник, **я хочу** заповнити розділи Profile, Experience, Education, Skills і Projects, **щоб** мати готове онлайн-резюме без верстки.

Acceptance criteria:
- Є 5 вкладок; кожна зберігається окремо кнопкою Save.
- Обов'язкові поля (ім'я ≥ 3 символи, спеціальність, email, телефон у форматі E.164) не дозволяють зберегти порожню форму.
- Після збереження показується повідомлення "saved"; після перезавантаження дані на місці.
- При виході з вкладки з незбереженими змінами показується діалог підтвердження.

## US-02. Пошук розробників
**Як** рекрутер, **я хочу** шукати розробників за ім'ям, спеціальністю або навичкою, **щоб** швидко знайти кандидата з потрібним стеком.

Acceptance criteria:
- Пошук працює без входу в систему.
- Регістр символів не впливає на результат.
- Порожній запит показує всіх розробників.
- Картка розробника веде на його публічне резюме.

## US-03. Завантаження резюме у PDF
**Як** рекрутер, **я хочу** завантажити резюме кандидата у PDF, **щоб** надіслати його колегам або зберегти в архів.

Acceptance criteria:
- Кнопка Download доступна на сторінці `/resume/{id}`.
- Файл називається `{Ім'я}_resume.pdf`, недопустимі символи в імені замінюються на `_`.
- PDF містить ті самі розділи, що й сторінка.

## US-04. Вхід через соціальні акаунти
**Як** розробник, **я хочу** увійти через Google або GitHub, **щоб** не створювати й не запам'ятовувати ще один пароль.

Acceptance criteria:
- На сторінках Login і Register є кнопки Google та GitHub.
- Після успішного входу користувач потрапляє на головну.
- Авторизований користувач, який відкриває `/login` або `/register`, перенаправляється на головну.

## US-05. Фото та зображення проєктів
**Як** розробник, **я хочу** додати фото профілю й скриншоти проєктів, **щоб** резюме виглядало переконливіше.

Acceptance criteria:
- Файл можна вибрати кліком або перетягнути в область завантаження.
- Після завантаження показується попередній перегляд, URL зберігається разом із формою.
- Без фото на сторінці резюме відображається іконка за замовчуванням.
